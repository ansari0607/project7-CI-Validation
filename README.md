# Project 7 - CI Validation For Terraform

[![Terraform Validation](https://github.com/ansari0607/project7-CI-Validation/actions/workflows/terraform.yml/badge.svg)](https://github.com/ansari0607/project7-CI-Validation/actions/workflows/terraform.yml)

## Objective

Automate Terraform validation using GitHub Actions.

## Checks

- terraform fmt -check
- terraform validate

## Result

Terraform code is automatically validated on every push and pull request.
